# Любимая дача

Статический сайт гостевых домиков в Каменномостском: https://dacha.sniper541.com/

## Сайт
- Тёмный адаптивный дизайн, реальные фотографии, анимация с поддержкой prefers-reduced-motion.
- Галереи домиков, территории, кухни и бани: клавиатура, свайп, полноэкранный просмотр.
- Форма дат и количества гостей готовит сообщение в WhatsApp. Она не проверяет доступность и не подтверждает бронь.
- Телефон, почта, карта проезда, отзывы и ответы на частые вопросы.

## Файлы
- site/index.html — содержание, цены и контакты.
- site/css/stay.css — оформление и адаптив.
- site/scripts/stay.js — галереи, меню, форма дат.
- site/scripts/gallery-data.js — списки фотографий.
- site/img — исходные фотографии сайта в WebP.
- site/scripts/optimize-images.mjs — сохранённый инструмент подготовки изображений.

Для работы сайта Node.js и отдельный сервер приложения не нужны. Nginx раздаёт каталог site. Шрифты загружаются из Google Fonts с системными запасными шрифтами. Все фотографии сохранены. Данные формы не хранятся на сервере.
